# PIZZA_SALES_EXCEL_DASHBOARD
# 🍕 Pizza Sales Performance & Revenue Dashboard

## 📌 Project Overview
An interactive Excel dashboard built on **45,000+ transactional records** to analyze consumer purchasing behavior, sales performance across pizza categories, and peak ordering hours.

## 🛠️ Tech Stack & Skills
* **Excel / Power Query:** Data cleaning, unpivoting, and ETL pipeline.
* **Power Pivot & DAX:** Star schema design, dynamic measures (`DISTINCTCOUNT`, `CALCULATE`, `ALL`).
* **Data Visualization:** Executive KPI cards, conditional formatting, dynamic slicers.

## 📊 Key Insights
* **Peak Ordering Hours:** Highest order volume occurs between 12:00 PM – 1:00 PM and 5:00 PM – 7:00 PM.
* **Category Contribution:** Classic category leads in total sales volume, while Supreme drives high Average Order Value (AOV).
